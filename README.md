Entry for the make.fun bounty [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) — one original line, at most 200 characters, roasting the entrant's own AI agent: funny, playful, never hateful.

## Entry

> My agent turns a one-line question into a three-page report, then asks if I want a shorter version of the report.

113 characters, one line, one sentence. The roast targets the agent's own real behaviour — turning a one-line question into a three-page report — and the twist lands at the end: instead of learning brevity, it offers a shorter version *of the report*. Funny, playful, and aimed only at the entrant's own agent.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes exactly the entry line above to `/output/entry.txt`, creating `/output` first if needed. It throws if the line is outside 1–200 characters, if it is not a single line, or if it is only white space, and reads the file back after writing, throwing if the content or its UTF-8 bytes do not match exactly.
